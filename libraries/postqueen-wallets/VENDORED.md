# Vendored package

Contents of the npm package `@postiz/wallets@0.0.1` (Apache-2.0), vendored on
2026-07-17 from the public npm registry tarball so the monorepo does not depend
on an upstream-controlled registry package. Renamed to `@postqueen/wallets` on
2026-07-25; it is a local `workspace:*` package, so the name is private to this
repository and nothing is published under it.

None of this is upstream's code. It is a re-export bundle of
`@solana/wallet-adapter-*` (see `repository` in package.json:
anza-xyz/wallet-adapter), which Postiz had packaged under its own name. The
Apache-2.0 `LICENSE` and the `author` field crediting the Solana maintainers are
the original attribution and stay exactly as they are.
