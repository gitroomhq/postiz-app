## Modifications

Compared to upstream Postiz (v2.24.0 base), this version:

- Rebrands the product as Postmonster: name, logo and icon set, color palette
  (Ink / Paper / Monster Lime / Coral), page titles, metadata and in-app copy.
- Rewrites the public README and adds this NOTICE file.
- Adds a "Source code" link in the application (Settings) pointing at the
  public repository of this modified version.
- Replaces the email wrapper branding (from name, header/footer, links).
- Removes upstream marketing surfaces from the UI: promotional testimonials,
  invented user-count claims, Chrome Web Store extension promo, affiliate
  upsell, one-click marketplace listings, and links to Postiz docs / n8n node.
- Hides install instructions for the upstream Postiz CLI and agent skill
  (upstream npm packages that are not part of this distribution).

Further functional changes (access control, TikTok Direct Post review
preparation, custom platforms) are listed in the repository history and the
project changelog as they land.
