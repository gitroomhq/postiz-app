# Localsell + Postiz

This folder describes the incremental integration of Localsell with this self-hosted Postiz instance.  Postiz remains the scheduling, media, social-channel and publishing platform; Localsell supplies authenticated business/store context and product references.

Read [architecture.md](architecture.md) first, then [authentication.md](authentication.md) before enabling any SSO endpoint.  The initial implementation has no automatic publishing or WhatsApp sending from conversational input.
